ZODIAC GATE — 십이지 언덕 방어

12간지 중 4명을 골라 파티를 짜세요. 첫 번째가 당신, 나머지는 AI 동료. 같은 캐릭터 중복 가능.

상성: 불 → 바람 → 번개 → 땅 → 물 → 불 (유리 ×1.5, 불리 ×0.5). 파티에 없는 속성은 2스테이지마다 약점으로 노려집니다.

캐릭터·환경 모델: Quaternius (CC0) · 이펙트: Kenney Particle Pack (CC0)

조작: PC는 우클릭 이동, 좌클릭으로 적 공격·상인 상점. 모든 캐릭터가 이동 중에도 공격합니다. 원거리는 사거리를 살려 카이팅. 모바일은 탭 이동, 적 탭 공격, 상인 탭 상점. 모바일은 자동 가로 화면.

온라인: 한 명이 방 만들기 → 뜨는 5자리 코드를 친구에게 보내기 → 친구는 코드 입력 후 참가. 서버가 중계하므로 어떤 네트워크에서도 연결됩니다. 빈 자리는 봇이 채웁니다.

맵: 기본은 라운드마다 랜덤 변경(언덕 방향·입구 수가 바뀜). 나무·바위 장애물이 매 라운드 새로 놓여 적의 진입 경로와 우리 이동을 막습니다.

강화: 라운드마다 각자 자기 캐릭터 강화 3개 중 1개 선택(12초, 미선택 시 랜덤). 역할 전용 강화가 항상 1개 포함. 좌측에 기여도 랭킹(피해·회복·받아낸 피해·처치·상태이상).

상점: 언덕 구석의 상인을 클릭(자동 이동) 또는 근처에서 P. 아이템 최대 6개, 골드는 적 처치 시 전원 동일 지급 + 라운드 보너스.

고지 판정: 언덕 아래에서 위를 공격하면 30% 확률로 MISS. 탱커가 램프로 밀려 내려가면 이 이점을 잃습니다.

웨이브를 전멸시켜야 다음 스테이지로 넘어갑니다. 스테이지가 바뀌면 전원 체력 회복·부활. 라운드 중 회복은 서포터만 가능.
